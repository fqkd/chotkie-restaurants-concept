# «Чоткие рестораны» — инициативная концепция мобильного приложения

Работающий веб-прототип приложения и отдельная коммерческая презентация для группы «Чоткие рестораны». Концепция помогает выбрать ресторан по атмосфере, кухне или поводу, а затем перейти к бронированию, событию, меню либо доступному сценарию заказа.

Проект создан ООО «ЭРГОХАВЭН» на основе открытых данных и не является официальным продуктом «Чотких ресторанов», «Чо-Чо», «Птички-Невелички», «Катеньки-Катюши» или Bésame mucho. Все подтверждения, оплаты и бронирования в прототипе безопасно симулируются внутри браузера; данные не отправляются.

## Маршруты

- `/` — интерактивный прототип. Состояния открываются через hash-маршруты, например `/#booking?restaurant=besame` и `/#payment-error?restaurant=cho`, поэтому прямое открытие и обновление страницы не дают 404 на GitHub Pages.
- `/case/` — адаптивная презентация из 11 содержательных разделов.

## Основные сценарии

- выбор ресторана по поводу и атмосфере;
- интерактивная карта OpenStreetMap с четырьмя подтверждёнными адресами, поиском и синхронным списком;
- законченный путь бронирования: ресторан → дата → время → гости → детали → подтверждение;
- афиша → событие → бронирование с сохранённым контекстом;
- меню и отдельные корзины ресторанов;
- демонстрационная ошибка оплаты, сохранение корзины и успешное восстановление;
- «ЧОткая карта» с подтверждёнными публичными правилами;
- история визитов, повтор заказа с проверкой цены и доступности, рекомендации других ресторанов;
- состояния загрузки, пустой корзины, недоступной позиции, ошибки и успеха.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm ci
npm run dev
```

Vite покажет локальный адрес в терминале. Презентация доступна по `/case/`.

## Проверки и production build

```bash
npm run lint
npm test
npm run build
npm run preview
```

Единая проверка:

```bash
npm run check
```

Адаптивный браузерный QA после сборки:

```bash
npm run qa
```

Сценарий QA проверяет прототип на 360, 390, 430 и 1440 px, презентацию на 390, 768 и 1440 px, горизонтальное переполнение, ошибки консоли, прямые hash-ссылки, карту, контакты и кнопки презентации. Он также проходит бронирование, оба перехода из афиши, заказ с ошибкой и восстановлением, изоляцию корзин, избранное и состояния меню. Скриншоты и отчёт создаются в `qa-output/` и не коммитятся.

## Сборка и публикация

`vite.config.ts` задаёт самостоятельный base path `/chotkie-restaurants-concept/` в GitHub Actions и формирует две точки входа: `/` и `/case/`. Workflow `.github/workflows/deploy.yml` выполняет чистую установку, линтер, тесты, production build и отдельный deployment GitHub Pages из ветки `main`.

Список проверенных фактов, гипотез и источников находится в [SOURCES.md](SOURCES.md).
